### Марковская модель погоды

**Задание:**  
Смоделировать погоду по дням:

- 1 — ясно  
- 2 — облачно  
- 3 — пасмурно  

Единица времени — **1 день**.  
Задать интенсивности переходов между состояниями.

**Требования:**
1. Выполнить моделирование в «реальном» времени с визуализацией.
2. Провести статистическую обработку результатов.
3. Сравнить эмпирическое распределение с теоретическим стационарным.
4. Сбор статистики и всей необходимой информации в .txt или .csv формат (.csv формат предпочтительней)

## Отчёт

В ходе выполнения лабораторной работы была разработана и исследована модель смены погодных состояний на основе непрерывной цепи Маркова с тремя состояниями:
- Ясно
- Облачно
- Пасмурно

Для описания процесса использовалась матрица интенсивностей переходов (Q), в которой диагональные элементы вычислялись как отрицательная сумма остальных элементов строки, что обеспечивает выполнение условия генератора непрерывной цепи Маркова: ∑j qij = 0

Моделирование выполнялось методом статистических испытаний. Время пребывания системы в каждом состоянии генерировалось по экспоненциальному распределению, а выбор следующего состояния осуществлялся на основе нормированных интенсивностей переходов.

Для нахождения стационарного распределения вероятностей была составлена и решена система линейных уравнений: πQ=0, с дополнительным условием нормировки: ∑ πi_i = 1
Решение системы выполнялось методом Гауасса.

В ходе экспериментов было установлено, что при увеличении времени наблюдения эмпирические вероятности постепенно приближаются к теоретическим значениям стационарного распределения, что подтверждает:
- Корректность реализации модели
- Правильность алгоритма имитационного моделирования

Также был реализован экспорт результатов (история переходов, матрица интенсивностей, итоговые вероятности) в файл формата .csv для последующего анализа

Лабораторная работа продемонстрировала практическое применение теории непрерывных цепей Маркова для моделирования случайных процессов и анализа их стационарного поведения.
