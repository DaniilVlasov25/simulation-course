### Пуассоновский поток. События на сервере
Моделирование потока заявок на сервер.

**Задание:**
- событие — поступление заявки;
- определить число заявок за интервал времени T;
- построить распределение числа заявок;
- вычислить среднее и дисперсию;
- сделать вывод.

## Отчёт
В ходе выполнения лабораторной работы была разработана и исследована модель простейшего (пуассоновского) потока событий на примере моделирования запросов к серверу.

Для описания процесса поступления запросов на сервер использовалась модель простейшего пуассоновского потока событий, обладающего следующими свойствами:
- Независимость: события (запросы) наступают независимо друг от друга
- Ординарность: в один момент времени может произойти только одно событие
- Стационарность: число событий на интервале зависит только от его длины, а не от начальной точки

Моделирование выполнялось на основе ключевого свойства простейшего потока: Интервалы времени между последовательными событиями имеют экспоненциальное распределение с параметром λ (интенсивность потока).

Алгоритм моделирования одного эксперимента:
- Задается начальный момент времени t₀ = 0
- Генерируется интервал до следующего события по формуле: τ = -ln(α)/λ
- Время обновляется: tᵢ₁ = t + τ
- Если tᵢ₊₁ ≤ T, фиксируется событие (запрос), иначе эксперимент завершается
- Подсчитывается общее число событий k за интервал времени T

В ходе экспериментов установленно:
- При увеличении числа экспериментов N эмпирические вероятности постепенно приближаются к теоретическим значениям распределения Пуассона
- Выборочные характеристики (среднее и дисперсия) стремятся к теоретическому значению λT

Лабораторная работа продемонстрировала практическое применение теории случайных потоков событий для моделирования нагрузки на сервер.
