### Моделирование случайных событий (GUI)

**Часть 1:**  
Приложение «Скажи “да” или “нет”».

**Часть 2:**  
Приложение «Шар предсказаний» (Magic 8-Ball).

# Часть 1 - Приложение «Скажи “да” или “нет”»

Для первой части лабораторной работы было реализовано случайное событие с двумя исходами:
- "Да"
- "Нет"

# Часть 2 - Приложение «Шар предсказаний» (Magic 8-Ball).

Для второй части лабораторной работы было реализовано одно случайное событие из группы возможных событий:
- Определённо да
- Без сомнений
- Можешь быть уверен
- Скорее всего да
- Спроси позже
- Лучше не говорить сейчас
- Точно нет
- Знаки указывают на нет
- Не рассчитывай на это
