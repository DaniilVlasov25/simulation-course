### Базовый датчик случайных чисел

**Задание:**
- реализовать базовый датчик случайных чисел;
- вычислить выборочные среднее и дисперсию:
  - для реализованного датчика;
  - для встроенного генератора языка программирования;
- размер выборки — **100 000 значений**;
- сравнить результаты с теоретическими;
- сделать вывод.

# Отчёт
Размер выборки: 100 000

Значение теоретических характеристик:
Равномерное распределение в интервале от 0 до 1
- Математическое ожидание: 0.5
- Дисперсия: 0.0833

Значение реализованные базовым датчиком:
- Выборочное среднее: 0.5006
- Выборочная дисперсия: 0.0835

Значение встроенного датчика:
- Выборочное среднее: 0.5012
- Выборочная дисперсия: 0.0837

# Вывод
По результатам можно сделать вывод, что значения, полученные для базового датчика (выборочное среднее: 0.5006 и выборочная дисперсия: 0.0835) практически совпадают с теоретическими значениями, тоже можно сказать и о значениях для встроенного датчика (выборочное среднее: 0.5012 и выборочная дисперсия: 0.0837), которые тоже практически совпадают с теоретическими значениями. Поэтому можно сказать, что реализованный датчик работает корректно и даёт хорошие результаты.
