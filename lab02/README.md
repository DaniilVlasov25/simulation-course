### Метод конечных разностей для уравнения теплопроводности

**Задание:**  
Реализовать моделирование изменения температуры в пластине на основе одномерного уравнения теплопроводности с использованием метода конечных разностей.

Выполнить моделирование с различными шагами по времени и по пространству.  
Заполнить таблицу значений температуры в центральной точке пластины после 2 секунд модельного времени.

| Шаг по времени, с \ Шаг по пространству, м | 0.1 | 0.01 | 0.001 | 0.0001 |
|-------------------------------------------|-----|------|-------|--------|
| 0.1 | | | | |
| 0.01 | | | | |
| 0.001 | | | | |
| 0.0001 | | | | |

**Сделать вывод.**

# Отчёт

**Начальные значения:**
- Материал: Медь
- Плотность: 8960
- Темплоёмкость: 385
- Теплопроводность: 385
- Модельное время: 2 с
- Темприратура слева: 100
- Темпиратура справа: -30
- Начальная темприратура: 20
- Толщина пластины: 0,1

|-------------------------------------------|-----|------|-------|--------|
| 0.1 | 100 | 20.7208 | 20.5929 | 20.5915 |
| 0.01 | 100 | 20.6825 | 20.5458 | 20.5444 |
| 0.001 | 100 | 20.6793 | 20.5417 | 20.5402 |
| 0.0001 | 100 | 20.6781 | 20.5404 | 20.5390 |
  
# Вывод
- Видно, что при большом шаге по пространству 0.1 результат получается не точным, так как при таком шаге сетка получаестя грубой и которая физически не позволяет решить уравнение теплопроводности, поэтому мы получили просто граничную температуру
- При уменьшение шага по пространству, значение температуры в центре практически перестаёт менятся и изменяются небольшие значения после запятой и результат становится более правдаподобным.
- Аналогично и при уменьшении шага по времени, значение темпиратуры в центре перестаёт менятся и становится более стабильной.
- Оптимальне параметры: при значении шагов 0.0001 по времени и 0.0001 по простарнству получаем наиболее точное значение темпиратуры 20.5390, но при шагах 0.001 по времени и 0.001 по простарнству получаем значение 20.5402. Поэтому оптимальными значениями является шаги 0.001 по простаранству и по времени.
